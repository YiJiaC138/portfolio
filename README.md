# Portfolio

A personal portfolio site built with **React**, **TypeScript**, and **Vite**. It showcases projects and skills with a modern, responsive UI (Bootstrap, Framer Motion).

---

## Live site

**Deployed webpage:** [link](https://yijiac138.github.io/portfolio/)

---

## Deploy

To publish the latest build to GitHub Pages, run:

```bash
npm run deploy
```

This builds the app and pushes the `dist` folder to the `gh-pages` branch.

---

## Development

- **Run locally:** `npm run dev`
- **Build:** `npm run build`
- **Preview production build:** `npm run preview`

---

## Tech stack

- React 19 + TypeScript
- Vite
- React Bootstrap, Framer Motion
- ESLint
